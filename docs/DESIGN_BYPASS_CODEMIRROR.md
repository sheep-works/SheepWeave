# 📐 設計書：Webview CodeMirror 2ペイン・サブエディタ＆バイパス翻訳

## 1. 概要・目的
本設計は、SheepWeaveのWebview内におけるテキスト編集体験を抜本的に強化するためのものです。
従来の `<a-textarea>` リスト方式（FilterView）を廃止し、`SheepGroom` で実績のある **CodeMirror 6 を左右2ペインで組み込んだ「サブエディタ / バイパス翻訳エディタ」** へと刷新します。

### 解決する課題
1. **パフォーマンスの向上**：セグメントが数百〜数千行あっても、DOM仮想化により一切カクつかず爆速で動作。
2. **本物のエディタ操作**：複数行の一括置換、マルチカーソル、矩形選択、正規表現検索をWebview内で実現。
3. **安全なバイパス翻訳**：本流（`.shwvt` / `project.json`）の順序や整合性を壊さず、抽出したサブセットだけを安全に編集・一括適用。

## 2. アーキテクチャ構成

```
[ VS Code メインエディタ (Target.shwvt) ] ── (正本・コンテキスト順序維持)
                  ▲

                  ▼
[ Webview / FilterView & BypassEditor ]
  ┌────────────────────────────────────────────────────────┐

  │  ・左右スクロール連動       │  ・リアルタイム差分検知   │
  └────────────────────────────┴───────────────────────────┘
```

## 3. 🛡️ 行数ガード（3重防壁セーフティロック）

CATツールにおいて最も致命的な「行ズレ事故」を100%防ぐため、以下の3重ガードを実装します。

### 第1防壁：入力・ペースト時の改行インターセプト
- **Enterキーの無効化**：
  CodeMirrorの `keymap` で `Enter` 単体キーをブロック。「セグメント内の改行は禁止されています」とツールチップを表示。
- **ペースト時のサニタイズ**：
  外部から改行を含むテキストが貼り付けられた場合、自動で半角スペースまたは `{/}` に置換して挿入（トランザクションフィルター）。

### 第2防壁：リアルタイム行数検証＆ズレハイライト
- `sourceLines = srcText.split('\n')` と `targetLines = tgtText.split('\n')` を常時比較。
- 行数が一致しない場合：
  - エディタヘッダーが警告色（Amber/Red）に変化。
  - 行数バッジ：`原文: 12行 / 訳文: 13行（行数が一致していません！）`
  - ズレが発生した行以降をエディタ内で視覚的にハイライト。

### 第3防壁：適用（Apply）ボタンのハードロック
- **「原文行数 === 訳文行数」が完全に成立している場合のみ**、「適用（Apply）」ボタンがアクティブ（緑色）になる。
- 1行でもズレている間はボタンが完全に無効化（disabled）され、事故データを本流に書き戻すことを物理的に防止。

## 4. データフローと同期ロジック

### ① 抽出フェーズ（Filter / Bypass）
1. フィルタ条件（キーワード、未確定行、類似度クラスタなど）に合致する `units` を抽出。
2. 抽出された各 unit の `src` を `\n` で結合 ➔ 原文CodeMirrorへセット。
3. 各 unit の `tgt`（または `pre`）を `\n` で結合 ➔ 訳文CodeMirrorへセット。
4. 元の `idx` の配列 `[0, 5, 12, 48, ...]` をマッピングテーブルとしてメモリ保持。

### ② 編集フェーズ（CodeMirror）
- ユーザーは右側ペインで自由に一括置換、タイピング、マルチカーソル編集を実行。
- 行数ガードがリアルタイムで健全性を監視。

### ③ 適用フェーズ（Apply）
1. 訳文テキストを `\n` で分割し、行ごとの配列を取得。
2. マッピングテーブルと照合し、変更があった行のみ `{ idx, tgt }` のペイロードを作成。
3. Webviewから拡張機能コアへ `update-units` メッセージを送信。
4. コア側（`CoreHandler.ts`）で `project.json` および `.shwvt` の該当行を安全に一括更新。

## 5. コンポーネント設計（Vue 3 / TypeScript）

### ① 共通エディタコンポーネント
`webview/src/components/common/DualCodeMirror.vue`
- `SheepGroom/frontend/src/components/AlignEditor.vue` の設計をベースに作成。
- Props: `sourceText`, `targetText`, `readonly`
- Emits: `update:targetText`, `apply`, `cancel`
- 内部機能：左右スクロール連動、行数ガード、`{|}`, `{/}` デコレータ、クイック置換ボタン。

### ② 適用先コンポーネント
1. **`webview/src/components/FilterView.vue`**：現在のリスト表示を `DualCodeMirror.vue` に置き換え。
2. **`webview/src/tabs/BypassTab.vue`（新設予定）**：類似文クラスタリング抽出、未確定行一括抽出用の専用タブ。
